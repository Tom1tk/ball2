# Docs on this branch

These are the original Ball2 design, task and progress documents, copied from `Assets/Docs/` on the
Unity `main` branch. They describe the Unity implementation and remain useful as the design source
of truth for behaviour, numbers and acceptance criteria.

They are **not** a description of the Godot project's current file layout or engine APIs. For that,
see:

- `../README.md` — how to run, build and test the Godot project.
- `../MIGRATION_PLAN.md` — Unity-to-Godot mapping, parity status and remaining work.

The active course in this branch is transcribed from `Assets/Scenes/Test2.unity` (500 × 500 m, 41
colliders, tall tower course); `Test.unity` is the older 100 × 100 prototype. Where the branch
intentionally differs from the Unity docs (translucent ball materials, placeholder hamster sprite,
direct-steering enemy AI), the difference is recorded in `../MIGRATION_PLAN.md` §3.
